# Dashboardblocks

> Open-source dashboard blocks for shadcn/ui. Install them with the shadcn CLI and own the code.

Install a block with `npx shadcn@latest add @dashboardblocks/<name>`. The CLI copies its source into your project, along with the components and other blocks it needs. Blocks work with Base UI, Radix UI and React Aria, every shadcn/create style and all five icon libraries.
